OLX Scraper

A Python web scraper for searching and collecting vehicle listings from OLX Portugal.

Features

* Search OLX listings by keyword
* Extract title, price, year, mileage, and gearbox
* Optional price and year filters
* Sort results by price
* Export results to Excel (.xlsx)
* Concurrent fetching for faster results

Requirements

Python 3.10+

Install dependencies:

pip install -r requirements.txt

Usage

Run:

python olx_scrapper.py

Enter your search query and follow the prompts.
